# Legendary Fortnight Calculator

A simple browser-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Clear, delete, and sign toggle controls
- Decimal support
- Keyboard input support
- Responsive layout

## Run locally

1. Open `index.html` in a browser.
2. Or serve the project with a local static server if preferred.

## Files

- `index.html` — calculator structure, styling, and logic
